# 拾笺 · 本地笔记库

一款**本地优先**的小型笔记软件。笔记默认只存在自己电脑里，断网也能用、不登录也能写；需要多设备时，用 QQ 邮箱登录后**手动点一次同步**才上云。

## 功能

- **树状目录**：类别可无限层级嵌套，点箭头收起 / 展开，支持拖拽笔记到别的类别
- **笔记管理**：新建、编辑、删除、收藏、搜索（标题 + 正文 + 标签）
- **双编辑模式**：Markdown（源码 / 分屏 / 纯预览三视图）与富文本所见即所得，随时互转
- **代码块**：Markdown 围栏代码块，自动语法高亮 + 一键复制；富文本里写完按 `Enter` 即跳出代码块，`Shift + Enter` 强制换行、`Ctrl / Cmd + Enter` 随时跳出
- **引用块**：富文本里按 `Enter` 在引用内分段，写到末尾再按一次就结束引用、接着写正文
- **笔记卡片操作菜单**：卡片右上角「⋯」/ 手机长按 / 电脑右键，唤起「打开 · 收藏 · 重命名 · 删除」菜单；删除走二次确认（手机上不再需要横向滑动工具栏去找删除按钮）
- **标签**：一篇笔记可打多个标签（最多 10 个）；左侧自动汇总标签云，点一下即筛选。点标签区右上「管理」打开**标签管理器**：搜索、按使用次数 / 名称 / 最近使用排序，支持**改名、删除、多选合并**（改名到已存在的标签会自动合并），所有操作批量应用到相关笔记
- **历史版本**：自动留存编辑历史，可预览任意版本并一键恢复（每条最多 40 个）
- **附件与图片**：工具栏「图片」按钮 / 拖拽 / `Ctrl+V` 粘贴，图片自动插入正文并内联显示；**点一下正文里的图片**，底部弹工具条可设 25% / 50% / 75% / 100% 或拖滑块（10%–100%），宽度随笔记保存、导出 Word 时按此宽度排版
- **导出**：单篇导出 Word（.docx）、PDF（调用系统打印）、Markdown（.md）
- **手机远程**：手机浏览器打开云端链接，用同一个 QQ 邮箱验证码登录即可看同一份笔记，**不必同一 WiFi**；窄屏自动切成顶栏 + 抽屉式目录
- **装到桌面**：手机端是标准 PWA，可「添加到主屏幕」当 App 用（全屏无地址栏）；带 Service Worker，首屏资源离线可读，长按图标有「新建笔记」快捷方式
- **同步**：本地优先，只有点「同步到云端」才联网；上传 / 拉取各一个按钮，互不干扰
- **回收站**：删除默认进回收站保留 30 天，可恢复 / 彻底删除；删除状态会作为「墓碑」同步，另一台设备拉取时不会把删掉的笔记复活
- **整库导出 Markdown**：点左下角「更多工具」→ 导出整本 Markdown，得到一个 zip：每篇一个带 YAML front matter 的 `.md`，图片和附件放在 `files/`，`README.md` 按类别做索引。可直接被 Obsidian / VS Code / Git / 任意 AI 工具读取
- **翻一条旧笔记**：随机重看一篇 7 天以上没动过的笔记，避免「记了就再也没看过」
- **手机系统分享**：安卓 Chrome 里从任意 App 点「分享 → 拾笺」，文字和链接直接存成笔记；桌面图标长按也有「随手记」快捷方式（iOS Safari 不支持 Web Share Target）
- **搜索增强**：空格分隔多个词是 AND，`tag:工作` 只按标签筛，命中关键词在结果里高亮
- **图片压缩**：插入超过 400KB 的 jpeg/png/webp 时自动缩到最长边 1600 并转 JPEG（GIF 动图不压），省本地空间也省云端额度
- **清理**：导入备份只留最近 30 份；彻底删除笔记后，同步面板会出现「清理云端无用附件」，一键删掉云端残留文件
- **其他**：深浅色主题、自动保存、全量 JSON 备份

## 三种用法

### 一、浏览器版（最轻）

需要 Node.js 18 或更高版本，**不需要安装任何依赖**：

```bash
cd note-app
node server.js
```

浏览器打开 <http://localhost:5173>。

- Windows：双击 `启动.bat`

### 二、云端同步（手机远程）

电脑和手机**不需要在同一个网络**。同步用的是一套云端仓库，按账号隔离。

**首次（电脑端）**

1. 点左下角 `同步到云端`
2. 填你的 QQ 邮箱 →「发送验证码」→ 收 6 位数字填进来（不用设密码，新邮箱首次验证即自动注册）
3. 点「上传本地笔记到云端」

**然后（手机端）**

4. 手机浏览器打开：<https://2120533470581252096.app.workbuddy.host/?sharecode=SSYXUMSNMI>

> 链接必须完整保留 `?sharecode=SSYXUMSNMI`。参数被聊天工具截断时会出现「链接不完整」或界面卡住、按钮无响应；用完整链接重新打开即可。v1.7.2 起页面会自动补参数，加载失败时也会给出「重新打开拾笺」按钮。
5. 用同一个 QQ 邮箱收验证码登录

**日常**

- 电脑改完 → `同步到云端` →「上传本地笔记到云端」
- 想取电脑的新内容 → 手机上点 ↻ →「从云端拉取到本地」
- **图片跟着笔记一起同步**：上传时会把 `data/files/` 里的原文件传到云端存储桶，拉取时再下载回本机（手机端存 IndexedDB）。所以手机上缺图时，先在电脑端重新「上传」一次，再到手机「拉取」
- 不点同步时，笔记只在各设备本地，**不走网络、不耗流量**
- **两端统一**按 `updatedAt`（最后修改时间）为准，后写覆盖先写；覆盖前会自动留一份历史版本，本地已有附件也不会被云端空元信息覆盖
- 注意：「导入备份」与「从云端拉取」是两套语义 —— 导入备份永远不覆盖已有笔记（同 id 跳过），只有云端拉取才按时间合并

**装到手机桌面（PWA）**

- 安卓：页面底部会自动出现「把拾笺放到桌面」提示条，点「添加」即可；也可以走 `☰ → 添加到手机桌面`，或浏览器菜单「添加到主屏幕 / 安装应用」
- iPhone（Safari）：分享按钮 →「添加到主屏幕」→「添加」；页面内点「添加」会给分步图示
- 微信 / QQ 内置浏览器不支持安装，需先「在浏览器打开」
- 装好后是独立的 `manifest.webmanifest` + `sw.js`：`display: standalone`，首屏静态资源预缓存（离线可读），跨域接口与 `/api/` 一律直连不缓存

> 局域网临时方案（同一 WiFi、无需账号）仍保留在代码里：`node server.js --lan` 会监听 `0.0.0.0` 并打印局域网地址 + 6 位访问码。已不再提供 `.bat` 入口。

### 三、桌面版（独立窗口）

```bash
cd note-app
npm install          # 首次会下载 Electron，约 100MB
npm run desktop      # 启动桌面客户端
```

打包成安装包（产物在 `release/`）：

```bash
npm run dist         # 当前系统；也可以 --win / --mac / --linux
```

> 桌面版数据存放在系统用户目录：
> - Windows：`%APPDATA%/拾笺/data`
> - macOS：`~/Library/Application Support/拾笺/data`
> - Linux：`~/.config/拾笺/data`
>
> 这样升级或重装软件不会丢笔记。

## 数据在哪

```
data/
├── db.json          # 类别、笔记正文、标签
├── files/           # 附件实体文件
└── versions/        # 每篇笔记的历史版本（一笔记一个 JSON）
```

- **备份**：点左下角下载图标导出完整 JSON；或直接复制整个 `data/` 目录
- **迁移**：把 `data/` 拷到新电脑相同位置即可；也可以导出 JSON 后在目标机器点「导入备份」，按 ID 合并去重，不会覆盖已有笔记，导入前会自动生成 `backup-*.json`
- 首次启动会自动生成示例笔记，可随意删除

## 导出说明

| 格式 | 说明 |
| --- | --- |
| Word | 直接生成 `.docx`，保留标题层级、加粗斜体、列表、代码块、表格，图片一并嵌入（无需 Word 在线） |
| PDF | 调用浏览器打印对话框，在「目标打印机」里选择「另存为 PDF」；已内置专门的打印样式（A4、页边距、代码块不跨页） |
| Markdown | 导出当前笔记的 `.md` 源文 |

| 操作 | 快捷键 |
| --- | --- |
| 搜索笔记 | `Ctrl / Cmd + K` |
| 新建笔记 | `Ctrl / Cmd + N` |
| 立即保存 | `Ctrl / Cmd + S` |
| 加粗 / 斜体（Markdown） | `Ctrl / Cmd + B` / `I` |

## 技术说明

- 后端：Node 内置 `http` 模块，零第三方依赖；JSON 持久化，写入用临时文件 + rename 保证原子性
- 前端：原生 JS，无构建步骤；`marked` 渲染 Markdown、`DOMPurify` 过滤 XSS、`turndown` 富文本转 Markdown、`highlight.js` 代码高亮、`docx` 生成 Word
- 云端同步：`public/sync.js`，调 WorkBuddy 云服务的 PostgreSQL（三张表 `sj_categories` / `sj_notes` / `sj_versions`，RLS 按 `owner_id = auth.uid()` 隔离），登录走邮箱 OTP 验证码，无密码存储
- 附件原文件上传到云端存储桶，`sj_notes.attachments` 里只存**稳定路径**；渲染时按需换临时签名 URL 或走带鉴权下载，不把签名地址写进正文（避免过期裂图）
- 所有库已放在 `public/vendor/`，**断网可用**
- 默认端口 5173，可用 `PORT=8080 node server.js` 修改

## 边界说明

- 默认只监听 `127.0.0.1`，仅本机可访问；同步走外部 HTTPS 服务，**不需要对外开端口**，也不用配内网穿透
- 局域网模式（`--lan` / `SHIJIAN_HOST=0.0.0.0`）的 6 位访问码只防同一 WiFi 下的顺手一翻，别拿它暴露公网
- 端口被占用时会自动向上顺延（5174、5175…），命令行窗口里会打印实际地址
- 附件单文件上限 20MB，每条笔记最多 10 个标签
- 手机端笔记存浏览器 localStorage，**图片和附件存 IndexedDB**（localStorage 只有约 5MB，装不下照片）；清「网站数据」会两者一起清掉，重要内容先同步到云端
- 富文本与 Markdown 互转依赖 HTML 结构，极复杂的排版（如嵌套表格）转换后可能有细微差异
- 历史版本节流：两次快照至少间隔 2 分钟，避免每次输入都产生版本
